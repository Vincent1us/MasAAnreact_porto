# Landing Page Portofolio (React + Vite + TypeScript)

## Cara menjalankan
1. Ekstrak file ZIP, buka foldernya di terminal / VS Code
2. `npm install`
3. `npm run dev`
4. Buka http://localhost:5173

## Mengubah isi
Semua data (nama, skill, proyek) ada di `src/data/portfolioData.ts`.
Foto sendiri: taruh di folder `public/` lalu isi `photo: "/foto.jpg"`.
